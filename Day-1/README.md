# Day 1: SQL Fundamentals & Data Definition

This directory contains introductory SQL scripts focusing on database setup, table management, conditional data filtering, and basic record updates.

## Topics Covered
* **Database Operations:** Creating and selecting the primary database (`college1`).
* **Table Creation & Constraints:** Implementing `PRIMARY KEY`, `UNIQUE`, and specific data types (`VARCHAR`, `FLOAT`, `DATE`).
* **Table Duplication:** Utilizing `LIKE` to copy structures and `AS SELECT` to clone structured subsets.
* **DML Operations:** Data manipulation using `INSERT`, `UPDATE`, `DELETE`, and filtered `SELECT` queries.

## File Overview
* `query_1.sql` - Contains solutions and implementation for Problems 1 through 20 covering `student`, `MCA`, and `MSe` tables.
